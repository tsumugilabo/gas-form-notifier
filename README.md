# gas-form-notifier — フォーム回答の整形・記録・通知

Google フォームの回答を受け取るたびに、

1. **正規化**（氏名の空白整理、電話番号の整形、メール形式チェック、項目名のゆれ吸収）
2. スプレッドシートの一覧シートに**追記**（二重送信は無視）
3. **メール**と（設定すれば）**Slack** に通知

を自動で行う Google Apps Script プロジェクトです。

## なぜ作ったか

「フォーム → スプレッドシート」は標準で連携できますが、実運用では

- 氏名に全角スペースや余分な空白が入る
- 電話番号の書式がバラバラ（`09012345678` / `090-1234-5678` / `090 1234 5678`）
- 送信ボタンの二度押しで同じ回答が2行入る
- 担当者が一覧を見に行かないと気づかない

といった小さな不便が積み重なります。それらを受信時に片付けます。

## 構成

| ファイル | 役割 | テスト |
|---|---|---|
| `src/normalize.gs` | フォーム回答 → 正規化レコード（純粋関数） | ✅ |
| `src/notify.gs` | メール本文・Slackペイロードの組み立て（純粋関数） | ✅ |
| `src/Code.gs` | トリガー処理、Sheets / MailApp / UrlFetch 呼び出し | — |
| `src/appsscript.json` | マニフェスト（タイムゾーン・最小スコープ） | — |

`normalize.gs` と `notify.gs` は **Google サービスに依存しない純粋関数**にまとめてあり、
Node.js 上でユニットテストできます（`src/Code.gs` が Google API との境界）。

## テスト

```bash
npm test
```

Node.js 18+ の標準テストランナーを使います（依存パッケージなし）。
`test/load.js` が `.gs` ファイルを読み込み、`normalize` / `notify` の
16 ケースを検証します（電話整形、別名項目、必須チェック、重複キー、通知本文など）。

## セットアップ

1. Google フォームの回答先スプレッドシートで **拡張機能 → Apps Script** を開く
2. `src/` の4ファイルを配置（[clasp](https://github.com/google/clasp) を使う場合は `.clasp.json.example` を参照）
3. **プロジェクトの設定 → スクリプト プロパティ** に設定

   | キー | 内容 |
   |---|---|
   | `NOTIFY_EMAIL` | 通知先メール（カンマ区切りで複数可） |
   | `SLACK_WEBHOOK_URL` | （任意）Slack Incoming Webhook |
   | `LOG_SHEET_NAME` | （任意）追記先シート名（既定: `受信ログ`） |

4. **トリガー** で「フォーム送信時 → `onFormSubmit`」を追加
5. `runSample()` を手動実行して、シート追記と通知を確認

## 動作イメージ

フォーム送信 → `受信ログ` シートに1行追記:

| 受信日時 | お名前 | 会社名 | メール | 電話 | お問い合わせ内容 | ステータス |
|---|---|---|---|---|---|---|
| 2026-04-05 12:00:00 | 山田 太郎 | 株式会社サンプル | taro@example.com | 090-1234-5678 | 見積もりをお願いします。 | OK |

同時に届く通知メール:

```
件名: 【フォーム受信】山田 太郎（株式会社サンプル）

フォームに新しい回答がありました。

受信日時 : 2026-04-05 12:00:00
お名前   : 山田 太郎
会社名   : 株式会社サンプル
メール   : taro@example.com
電話     : 090-1234-5678

── お問い合わせ内容 ──
見積もりをお願いします。

一覧シート: https://docs.google.com/spreadsheets/d/xxxx
（7 行目に追記）
```

必須項目が空・メール形式が不正な回答は、シートに `要確認` として記録したうえで
警告メールを送ります（回答を取りこぼしません）。

## 使用スコープ

`appsscript.json` で要求するのは最小限です。

- `spreadsheets.currentonly` — バインドされたシートのみ
- `script.send_mail` — 通知メール
- `script.external_request` — Slack Webhook（設定時のみ実際に使用）
